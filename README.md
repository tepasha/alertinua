# AlertInUA — Електронний вартовий спокою

> *«Занурившись у мовчазні глибини цього коду, миттєво відчуваєш пульс цифрового сьогодення. Це не просто рядки символів чи алгоритмів — це електронний щит, який бере сирі дані про тривоги й миттєво перетворює їх на чіткий сигнал, щоб зберегти найцінніше — час і життя.»*

## 📖 Про проєкт

**AlertInUA** — це інструмент для швидкої та ефективної взаємодії з даними про повітряні тривоги в Україні, реалізований на низькорівневих і високопродуктивних мовах програмування.

Репозиторій містить дві окремі реалізації:
* ⚙️ **C** — легке, продуктивне рішення для вбудованих систем (Embedded / IoT) та системних модулів.
* 🦀 **Rust** — безпечне, паралельне та надшвидке рішення для надійних сервісів.

> *«Цей проєкт працює мов коліщатка у високоточному швейцарському годиннику: чистий, суворий та функціональний код, де кожна строчка служить практичній меті.»*

---

## 🛠️ Реалізації

### 1. Реалізація на C (`/c`)

Призначена для використання в мікроконтролерах, вбудованих пристроях та середовищах із обмеженими ресурсами.

**Збирання та запуск:**
```bash
cd c
make
./alertinua
```

### 2. Реалізація на Rust (`/rust`)

Призначена для максимальної безпеки роботи з пам’яттю та високої швидкості обробки запитів.

**Збирання та запуск:**
```bash
cd rust
cargo build --release
cargo run
```

## 🚀 Основні переваги

* ⚡ **Мінімальні затримки:** Використання C та Rust забезпечує максимальну швидкість обробки даних без системного оверхеду.
* 🔒 **Надійність:** Висока стійкість до збоїв у режимі 24/7.
* 🔌 **Універсальність:** Можливість запускати як на мікроконтролерах (ESP32, Raspberry Pi), так і на потужних серверах.
