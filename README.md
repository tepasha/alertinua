## 📌 Опис проєкту

**`alertinua`** — це прошивка/компонент для мікроконтролерів сімейства ESP32, написана на фреймворку **ESP-IDF**. Проєкт дозволяє пристрою автономно підключатися до мережі Інтернет через Wi-Fi, отримувати статус повітряних тривог у вибраній області/районі України через REST API та керувати периферією (LED-стрічки, дисплеї, зумери, реле).

Пристрій ідеально підходить для створення фізичних індикаторів безпеки, настільних годинників з функцією сповіщення або промислових контролерів.

---

## ✨ Особливості

* ⚡ **Низька затримка:** Пряме опитування API за допомогою `esp_http_client`.
* 🧩 **Модульність:** Легка інтеграція як окремого компонента в будь-який проєкт ESP-IDF.
* 🌐 **Wi-Fi Provisioning / Config:** Зручне налаштування мережі та API-ключа.
* 🔒 **Захищене з'єднання:** Підтримка HTTPS (TLS/SSL) через `mbedTLS`.
* 💡 **Гнучка індикація:** Проста прив'язка подій тривоги до GPIO (світлодіоди, пищалки, реле).

---

## 🛠️ Вимоги

* **Фреймворк:** ESP-IDF v5.0 або новіша
* **Плата:** LILYGO T-Display-S3 AMOLED ESP32-S3
* **Токен:** API-ключ для доступу до сервісу тривог (наприклад, [alerts.in.ua](https://alerts.in.ua/))

## 🔌 Апаратне підключення (Hardware)

Приклад типової розпіновки (може бути змінена через `menuconfig` або в коді):

| Периферія | Опис | Зазочуваний GPIO |
| :--- | :--- | :--- |
| **Status LED** | Індикатор наявності тривоги (Червоний) | `GPIO 2` |
| **Buzzer** | Звуковий сигнал про початок тривоги | `GPIO 4` |
| **Wi-Fi LED** | Індикатор статусу підключення Wi-Fi | `GPIO 15` |
